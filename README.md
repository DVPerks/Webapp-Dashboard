# WebApp Dashboard

**[Live Demo](https://dvperks.github.io/portfolio/project-viewer.html?project=3)** | **[Developer Portfolio](https://dvperks.github.io/portfolio/)**

A responsive, interactive web dashboard built with JavaScript, Chart.js, and SCSS/Sass. The application demonstrates data visualization, dynamic interface behavior, responsive layouts, form validation, and persistent user preferences.

## Features

- Interactive traffic charts and data visualizations.
- Social media statistics and dashboard widgets.
- Dynamic interface interactions.
- Messaging interface with client-side form validation.
- Customizable user settings.
- Persistent preferences using local storage.
- Responsive dashboard layout.

## Built With

- JavaScript (ES6+)
- HTML5
- CSS3
- SCSS/Sass
- Chart.js
- Local Storage

## Technical Highlights

### Data Visualization

Chart.js presents dashboard information through interactive charts, providing a visual representation of traffic and statistical data.

### Responsive UI Development

The dashboard combines multiple interface components into a responsive layout designed to accommodate different viewport sizes.

### Dynamic Interface Behavior

JavaScript manages interface interactions, form behavior, and user preference updates through DOM manipulation and event handling.

### Form Validation

Client-side validation provides feedback when required messaging fields are incomplete or contain invalid input.

### Persistent User Preferences

Local storage preserves selected user settings between browser sessions.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/DVPerks/Webapp-Dashboard.git
cd Webapp-Dashboard
```

Install the project dependency:

```bash
npm install
```

Serve the application using a local web server:

```bash
python -m http.server 8000
```

Open http://localhost:8000/ in your browser.

On Windows, `py -m http.server 8000` can also be used.

## Development Focus

This project demonstrates the implementation of a multi-component dashboard interface using JavaScript and Chart.js, with an emphasis on responsive design, data presentation, user interactions, and browser-based persistence.

The dashboard is a frontend demonstration and does not require a production backend or live analytics service.
